# AI Evolution Log

Track whether the **AI Sales Employee** is improving toward the North Star:

> **Generate Qualified Buyers Automatically.**

One line per sprint is enough. Do not invent fake metrics — leave cells blank or `n/a` until measured.

## Metrics

| Metric | Meaning |
|--------|---------|
| Lead Precision | Of leads kept, how many are real demand |
| Lead Recall | Of true demand seen, how much we captured |
| Spam Rate | Noise / false positives |
| Buyer Conversion | Lead → Qualified Buyer |
| Campaign Success | Campaigns that moved Buyer / Revenue KPIs |
| Knowledge Growth | Useful rules / coverage added |
| Automation Rate | Work done without manual ops friction |
| Publish Success | Successful publishes / attempts |
