Thông báo Telegram

Gửi lead về bot Telegram của chính bạn. Token được mã hoá bằng kho bảo mật của Windows.

Hướng dẫn tạo bot Telegram và lấy Chat ID
  1. Mở Telegram, tìm @BotFather và gửi /newbot.
  2. Đặt tên bot, sau đó đặt username kết thúc bằng bot (ví dụ houseandlife_agent_bot).
  3. BotFather trả về HTTP API Token dạng 123456789:AAH... — dán vào ô Bot Token.
  4. Bấm vào bot vừa tạo và gửi /start để bot được phép nhắn cho bạn.
  5. Lấy Chat ID: nhắn cho @userinfobot (trả về ID số), hoặc gọi https://api.telegram.org/bot<TOKEN>/getUpdates và lấy message.chat.id.
  6. Dán Chat ID, bật kênh, bấm Gửi tin thử để kiểm tra.

Lưu ý: nếu bot chưa nhận được /start từ bạn, Telegram sẽ trả lỗi “chat not found”.
